# CAUGHT! — Design Direction

## Confirmed Direction

The user approved a **bold red-and-cream reveal, oversized text, and a centered photo**. Use this direction directly. No further style exploration is needed.

## Palette and Type

- Cream background: `#FFF4DE`.
- Dark ink: `#251C19`.
- Alarm red: `#B92D24`.
- Secondary text: `#6B574C`.
- Use installed Segoe UI. Large bold headings, readable body text, obvious buttons.
- No downloaded assets, web fonts, extra UI packages, or flashing/strobe effects.

## Screens

| State | Primary message | Primary control |
| --- | --- | --- |
| IDLE | Touch it. Regret it. | ARM SYSTEM |
| ARMING | Camera warming up, then Hands off in… 3, 2, 1 | CANCEL |
| ARMED | System Armed. This laptop is being watched. Don't touch it. | DISARM |
| TRIGGERED | CAUGHT IN 4K / BRO THOUGHT NOBODY WOULD NOTICE | STOP ALARM & RESET |

The reveal fills the current display. Put the photo in the center, preserve its aspect ratio, and keep the stop button visible. A simple windowed setup screen is enough. State names must remain visible and understandable without relying on color.

## Fallback and Exit

If the camera fails, show: **CAMERA FAILED, BUT YOU'RE STILL CAUGHT.**

Escape resets. Alt+F4 exits. The reveal is a normal fullscreen window, not a locked desktop. No fake police, security, or upload claims.
