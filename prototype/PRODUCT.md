# NICE TRY.
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated: dependency-free HTML, CSS and JavaScript. User requested a prototype in under ten minutes, with no landing page.

## Users
Laptop owners stepping away for coffee who want to discourage friends from tampering with their session.

## Product Purpose
A funny proximity-based laptop guardian. This deliverable is a brand kit and interactive web prototype of dashboard, phone companion, setup, alerts and settings.

## Capabilities and Constraints
All device, input and locking data is simulated. A native implementation would own Bluetooth observation, OS locking and notifications. Signal strength indicates approximate proximity, not an exact 10 m boundary. Activity while away is a possible tampering event, not proof of identity. Phone return must never automatically unlock a real session. No photography, key contents or person identification.

## Brand Commitments
Funny, friendly anti-prank purpose. Proposed name: NICE TRY. No landing page. Scope is a prototype, not native protection.

## Evidence on Hand
Empty repository. No real device data or commercial claims. Technical sources are recorded in README.md.
